 Graduates Employment System (GES) — Zarqa University
 Description

The Graduates Employment System (GES) is a full-stack employment platform designed to connect university graduates with employers in an efficient and intelligent way.

The system provides job matching and recommendation features powered by AI-based CV analysis, helping graduates find suitable job opportunities while enabling employers to discover qualified candidates easily.

 Graduate Profile Management
 Employer Dashboard
 CV Upload & Analysis System
 AI-Based Job Matching & Recommendations
 Job Posting & Application System
